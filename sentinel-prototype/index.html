Tech stack

MOD.01

Anthropic Claude

Powers response generation and the resample-based semantic entropy check for the Performance lane. This prototype calls Claude directly from the browser with a bring-your-own key.

reasoning
MOD.02

NVIDIA NIM / Triton

Production path: the Responsibility classifiers and embedding models would run as NVIDIA NIM microservices on Triton Inference Server for low-latency, high-throughput serving at enterprise scale.

planned — production
MOD.03

Embeddings + Vector store

This prototype approximates semantic clustering with lightweight word-overlap. Production would swap in sentence-transformer embeddings and a vector store (e.g. Milvus) for real clustering at scale.

planned — production
MOD.04

Static frontend

Vanilla HTML, CSS and JavaScript — no build step, no framework. Runs from a single file so it's trivial to clone, open, and demo from any machine.
